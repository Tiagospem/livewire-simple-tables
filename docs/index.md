# Introduction

Livewire Simple Tables is a powerful Laravel package that simplifies the creation of data tables in your Livewire applications. With a focus on ease of use, flexibility, and performance, this package allows you to quickly build interactive tables with advanced features like:

- Searchable and sortable columns
- Pagination with customizable settings
- Row actions and bulk actions
- Detailed row views
- Custom filters
- Theme customization
- And much more!

The package is designed to be intuitive for beginners while providing the flexibility and extensibility needed for advanced use cases. Whether you're building a simple admin panel or a complex data management system, Livewire Simple Tables has you covered.

## Why Choose Livewire Simple Tables?

- **Simple API**: Create tables with just a few lines of code
- **Performance-Focused**: Optimized for handling large datasets
- **Highly Customizable**: Adapt every aspect of your tables to match your application's needs
- **Laravel & Livewire Native**: Built specifically for Laravel and Livewire applications
